ek.ocr#

OCR evaluation – ek’s first concrete instance, built on ocracy.

OCR is the noisiest special case of information extraction. This subpackage adds the OCR-specific pieces on top of ek’s source-agnostic core:

  • ocracy_backend() / read_text() – a thin bridge that turns ocracy’s 16-engine fleet into an image -> OcrResult callable. The dependency arrow is strict: ek -> ocracy (via the ek[ocr] extra), never the reverse. ek core depends only on the OcrResult shape (.text / .blocks / .mean_confidence), so the benchmark below evaluates any image -> OcrResult callable – ocracy or your own.

  • profile() – per-engine capability profiles (who emits real vs model-guessed geometry, who is calibrated, who yields table structure), distilled from misc/docs/ek_01. ek treats these as claims to verify empirically.

  • evaluate_ocr() / add_gold_item() – run a fleet over a gold corpus, score with CER/WER (globally accumulated), slice the report, and persist gold + results to the dol stores under ~/.local/share/ek/.

  • table_from_ocr() / has_table_structure() – recover the existing ek.metrics.tables.Table from an OcrResult (whose engine-specific table

    data lives only in .raw/.markdown) so the table metrics (TEDS / GriTS) can score OCR table output uniformly. The per-engine extractor is injected/registered under the "table_parsers" namespace (open-closed); see ek.ocr.tables.

Heavy engine SDKs and credentials are never required to import this module; they are checked at call time via ek.registry.check_requirements().

ek.ocr.engine_yields_tables(engine)[source]#

Whether engine’s capability profile claims scoreable table structure.

A convenience over ek.ocr.profile(): returns the engine profile’s tables flag. ek treats the profile as a prior (Azure DI, AWS Textract, PaddleOCR and the markdown engines are expected to yield scoreable tables; Google Vision is not), to be verified empirically by actually running table_from_ocr(). Use it to skip table scoring for engines that cannot emit cells in the first place.

Return type:

bool

ek.ocr.table_from_ocr(ocr_result, *, parser=None)[source]#

Extract a normalized Table from an OcrResult.

The single seam ek’s table metrics (TEDS / GriTS) use to score OCR table output uniformly. Returns the recovered Table, or None when the result carries no recoverable table structure.

Parameters:

  • ocr_result (Any) – Any OcrResult-shaped object. ek reads only its .raw (the engine-specific payload), .markdown (VLM/markdown engines), and .meta – never ocracy types, so any image -> OcrResult callable’s output works.

  • parser (Union[None, str, Callable[[Any], Any]]) –

    How to turn the raw payload into a table (dependency injection / open-closed). One of:

    • None (default): try the built-in safe heuristics – .raw is already a Table, a 2-D grid, or a <table>...</table> HTML string; or .raw/.meta is a mapping carrying one of {tables, table, cells, grid, html}; or .markdown contains an HTML <table>. Returns None if none match – it never guesses wildly.

    • a str: the name of a parser registered under "table_parsers" (per-engine extractor), resolved from ek.registry.

    • a callable (raw) -> Table | grid | html | None: an inline per-engine extractor. It receives the result’s .raw (falling back to the result itself when there is no .raw).

  • through (Any non-None value an injected parser returns is fed)

Return type:

Table | None

:param Table.coerce(): :param so a parser may yield a Table: :param a 2-D grid: :param or HTML.:

Return type:

Optional[Table]

Returns:

A non-empty Table, or None when no table structure is recoverable. An empty Table (no rows/cells) is normalized to None so the predicate has_table_structure() and downstream metrics see “no table”, not a degenerate one.
