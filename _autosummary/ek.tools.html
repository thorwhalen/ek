ek.tools#

Small, CLI-friendly functions over the ek core (the dispatch surface).

These are thin, string-in/value-out wrappers designed for triple dispatch (CLI today, HTTP/UI later). The single _dispatch_funcs list is the SSOT of what ek.__main__ exposes, so there is no duplicated command registration, and each function’s signature is its command-line interface.

Run them from the shell:

python -m ek cer "hello wrld" "hello world"
python -m ek where
python -m ek check tesseract

ek.tools.pass_k(n, c, k=1)[source]#

pass@k (capability) and pass^k (reliability) from c successes in n trials.

pass@k asks “can it ever do this?”; pass^k asks “does it do this every time?” – and only the second is a production number.

Example:

python -m ek pass-k 10 9 --k 8      # a 90%-reliable agent, judged over 8 trials
Return type:

dict
